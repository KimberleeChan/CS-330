# CS 330 Portfolio Reflection

### How do I approach designing software?

Working on this project helped me learn how to break down objects into smaller shapes when designing a 3D scene. I chose to create my Pathfinder 2E setup on a table, which included books, a notebook, a Diet Coke can, a 
mechanical pencil, and different dice. I had to figure out which shapes to use for each object and how to position and scale them to make them look right. For example, I created the mechanical pencil by combining multiple
shapes, including cylinders for the body and other parts, a cone for the tip, and two boxes for the clip. I had to position the shapes carefully so the different pieces lined up and looked like parts of the same pencil. I 
also had to choose textures that fit the objects and adjust the lighting to improve how the scene looked. This process taught me to think about how individual parts work together to create a complete scene. I can use the 
same approach in future projects by breaking larger problems into smaller parts and working through them one step at a time.

### How do I approach developing programs?

Throughout this project, I worked on the scene in stages by adding objects, making them interactive when required, applying textures, and adjusting the lighting. Testing the scene as I went helped me see how changes to 
the code affected the results. I also had to make adjustments when things did not look the way I expected. One challenge was finding textures that matched the look I wanted for my objects. Some of the textures I wanted 
were difficult to find, so I had to change some of my original ideas. I also learned that getting objects to look right involved more than choosing the correct shapes. Their positions, sizes, textures, and lighting all 
affected the final result. As I worked through the milestones, I became more comfortable making changes and checking the results instead of trying to get everything right the first time. This gave me more experience with
testing, troubleshooting, and improving a program through repeated changes.

### How can computer science help me in reaching my goals?

This project gave me more experience with C++ and showed me how code can be used to create a complete 3D scene. I learned more about working with shapes, textures, materials, lighting, and interactive graphics. These are 
skills I can build on as I continue working toward my bachelor's degree in computer science. I also gained more experience with problem-solving because I had to figure out how to create objects from different shapes and
adjust the scene when the results did not match what I wanted. Professionally, I can use the programming and troubleshooting skills I developed in different areas of technology. I am still exploring which career path I want
to pursue, but this project gave me more experience with a different area of computer science and helped me understand more about the work involved in developing graphics applications.
